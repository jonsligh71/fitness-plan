# Fitness Plan

Phone-first 12-week workout tracker.

## Publish with GitHub Pages
1. Upload these files to the root of the `fitness-plan` repository.
2. In GitHub: Settings → Pages.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then Save.
5. Open the Pages URL in Safari on iPhone.
6. Share → Add to Home Screen.

The app uses browser local storage for workout data and a service worker for offline use after the first successful load.
